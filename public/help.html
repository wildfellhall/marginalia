MARGINALIA HELP

Help & support

How to add readings, annotate sources, and back up your notes.

Annotate a website

  1. Pin Marginalia in Chrome's Extensions menu. Open an article, website, or Project Gutenberg HTML book.
  2. Click Marginalia and choose Annotate this page. If the page was open before installation, refresh it once.
  3. Select a passage, choose a tool and color, add an optional note and comma-separated labels, then save.
  4. Revisit the same URL to restore highlights. Click the Marginalia badge to reopen your notes.

Highlight and underline tools need selected text. Margin notes, sticky notes, flags, tabs, and bookmarks can also save a page position. Click Open my library in the popup to see all your readings.

Read PDFs and EPUBs

In the library, choose Add reading → Import a file. Supported files are PDF, DRM-free EPUB, HTML, text, and Markdown. The file limit is 75 MB. EPUBs are limited to 20 MB of extracted text and embedded images. Markdown is displayed as plain text.

PDFs open in Marginalia's reader with page controls and a selectable text layer. Download PDFs from the browser's built-in viewer, then import them. Scanned pages without text support page notes and markers but cannot be highlighted; OCR is not included. Encrypted EPUBs are not supported.

Find and organize annotations

Search titles, passage text, notes, and labels in the library. Use All annotations for annotation-type filters, My labels for named collections, and Bookmarks for saved places. Use the pencil icon to edit an annotation or the trash icon to delete it.

Organize readings into folders

For example, create a folder for Biology 101 or a research paper. Use labels such as Key terms, Essay evidence, or Review to group annotations across readings.

Open My folders → New folder to create a named, colored collection. Use the folder icon on a book or annotation in the library or reader to choose one or more folders, or create one while organizing. Uncheck a folder to remove an individual membership. Adding a book includes all its annotations, including future notes. An annotation can also be saved independently; unchecking that independent membership does not remove it while its book is included.

Open a folder to search its titles, notes, highlighted words, or labels. Use Edit folder to rename it or change its color. Removing a book from a folder or deleting a folder never deletes the original books or annotations. Folders are saved on this device and included in your backups. Older backups without folders still work.

Keep a backup

Open Settings & backup and export your library. The downloaded JSON includes notes, labels, folders, imported content, and original PDF files. Import it into another installation to move your collection. Import keeps newer local edits when record IDs match.

Backups are unencrypted. Store them privately. There is no account or automatic cross-device sync; the installed extension and web preview have separate libraries. Uninstalling the extension can remove local data.

When something does not appear

  • No toolbar: refresh the website after installation and make sure Chrome's site-access setting allows Marginalia on that site.
  • No highlight on a revisit: verify the URL, including query parameters. If the website rewrote or removed the original passage, the saved quote remains in the library but may no longer attach to the page.
  • A protected page: Chrome settings, extension stores, built-in PDF viewers, closed shadow roots, and embedded cross-origin frames cannot be annotated directly.
  • Missing PDF after an import: restore a backup that includes the PDF file, or import the original file again. A newly imported file becomes a new library entry.
  • Storage or import error: export what you can, check available device space, and try a smaller file. The standalone web preview has a smaller storage quota than the installed extension.

Clear local data

Choose Settings & backup → Delete all local reading data, review the confirmation, and choose Delete everything. Downloaded backups are not deleted. This action cannot be undone without a backup.
